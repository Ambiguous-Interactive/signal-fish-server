# Agent Quality

Review evidence before claiming completion. Inspect the diff, run risk-proportionate checks, and report unresolved uncertainty plainly.

## Workflow

1. Read [agent-self-review-checklist.md](references/agent-self-review-checklist.md) before handing off implemented work.
2. Read [code-review-checklist.md](references/code-review-checklist.md) when reviewing a patch or pull request.
3. Read [agentic-workflow-patterns.md](references/agentic-workflow-patterns.md) when designing or evaluating automated agent workflows.
4. Separate verified facts, inferences, and untested assumptions in the result.
5. Prefer raw evidence such as diffs, test output, and traces over confidence statements.
